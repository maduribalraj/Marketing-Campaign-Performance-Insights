# Marketing Campaign Performance Insights

## Project Overview
This project analyzes marketing campaign performance to evaluate the effectiveness of different marketing channels, understand customer engagement, and measure campaign profitability.

The dashboard provides actionable insights into impressions, clicks, conversions, revenue, advertising spend, and Return on Investment (ROI).

## Key Performance Indicators (KPIs)
- Total Impressions
- Total Clicks
- Total Conversions
- Total Revenue
- Total Marketing Spend
- Click-Through Rate (CTR)
- Conversion Rate
- Cost Per Click (CPC)
- Cost Per Acquisition (CPA)
- Return on Investment (ROI)

## Key Insights
- Identify the best-performing marketing campaigns.
- Compare performance across marketing channels.
- Analyze customer engagement and conversion trends.
- Evaluate advertising costs and revenue generation.
- Identify opportunities to optimize marketing budgets.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Business Objective
To help businesses make data-driven marketing decisions, optimize advertising budgets, improve customer conversions, and maximize marketing ROI.

## Project Outcome
An interactive Power BI dashboard that transforms raw marketing data into meaningful business insights and supports better marketing strategies.
